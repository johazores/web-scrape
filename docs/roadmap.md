# Roadmap

The project will remain a focused website migration and SEO preservation tool rather than a general-purpose large-scale crawler.

## Current priorities

- Stabilize the canonical page export format.
- Expand extraction fixtures for common CMS structures.
- Improve report clarity for redirects, missing metadata, broken internal links, and duplicate content.
- Strengthen safe authentication and browser-rendering boundaries.
- Add repeatable migration examples for WordPress, Next.js, Astro, Hugo, and custom CMS imports.

## Planned improvements

- Export schema versioning.
- Better incremental and changed-page crawls.
- Additional media and structured-data validation.
- Clearer progress and resume summaries.
- More integration fixtures using local test websites.

## Out of scope

- Bypassing access controls or anti-bot protections.
- Crawling websites without authorization.
- High-volume distributed crawling.
- Search-engine indexing or general web archiving at internet scale.
- Automatic publication into every CMS.
