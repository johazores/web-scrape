# Code of Conduct

Be respectful, constructive, and considerate in issues, pull requests, reviews, and project discussions.

Contributors must not use this project to request help bypassing access controls, ignoring website ownership, extracting private information, or violating legal and ethical boundaries.

Harassment, discrimination, threats, publishing private information, deliberate disruption, and repeated hostile behavior are not accepted.

Report conduct concerns privately through the maintainer's GitHub profile. Maintainers may edit or remove content, close discussions, restrict participation, or block contributors when necessary to protect the project and community.
